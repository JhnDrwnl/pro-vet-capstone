# Vaccination Auto-Scheduling Feature

## Overview

The Vaccination Auto-Scheduling feature automatically creates vaccination appointment suggestions for pets based on their age, species, and vaccination history. This system ensures pets receive timely vaccinations according to veterinary best practices and helps pet owners stay on top of their pets' healthcare needs.

## Features

### 🎯 **Smart Vaccination Series Management**
- **Puppy/Kitten Series**: Automatically tracks multi-dose vaccination sequences
- **Adult Boosters**: Manages annual and triennial booster schedules
- **Species-Specific Protocols**: Different schedules for dogs, cats, and other pets
- **Age-Based Calculations**: Determines appropriate vaccines based on pet's age

### 📅 **Automatic Scheduling**
- **Next Due Date Calculation**: Automatically determines when next vaccines are due
- **Priority-Based Suggestions**: High priority for overdue vaccines, medium for upcoming
- **Service Matching**: Intelligently matches vaccine types to available clinic services
- **Batch Processing**: Can process all pets for a user simultaneously

### 🔄 **Real-Time Updates**
- **Progress Tracking**: Shows vaccination completion progress
- **Overdue Alerts**: Highlights vaccines that are past due
- **Series Progress**: Tracks multi-dose vaccine sequences
- **Automatic Updates**: Refreshes suggestions when vaccinations are completed

## Usage

### For Pet Owners

1. **View Vaccination Schedule**
   - Navigate to the Vaccination Auto-Scheduler component
   - Select your pet to see their vaccination schedule
   - View progress and upcoming vaccinations

2. **Schedule Appointments**
   - Click on any vaccination suggestion
   - Review details and suggested dates
   - Convert suggestion to actual appointment

3. **Run Auto-Scheduling**
   - Click "Run Auto-Scheduling for All Pets"
   - System analyzes all pets and creates suggestions
   - Review and schedule as needed

### For Veterinarians

1. **Enhanced Vaccination Records**
   - Automatic vaccination record generation
   - Series progression tracking
   - Next due date calculations

2. **Patient Management**
   - View vaccination series progress
   - Identify overdue vaccinations
   - Track multi-dose sequences

### For Administrators

1. **Service Configuration**
   - Mark services as vaccination services
   - Configure vaccination types and schedules
   - Manage vaccination series templates

2. **System Monitoring**
   - Monitor autoscheduling performance
   - Track suggestion conversion rates
   - Manage scheduled functions

## API Endpoints

### Cloud Functions

#### `runVaccinationAutoScheduling`
```javascript
// Call from frontend
const functions = getFunctions();
const runAutoScheduling = httpsCallable(functions, 'runVaccinationAutoScheduling');

const result = await runAutoScheduling();
console.log('Suggestions created:', result.data.suggestionsCreated);
```

#### `scheduledVaccinationAutoScheduling`
- Automatically runs daily at 6 AM EST
- Processes all users with pets
- Creates vaccination suggestions as needed

### Frontend Services

#### `autoScheduleVaccinations(pet, existingVaccinations, user)`
```javascript
import { autoScheduleVaccinations } from '@/services/vaccinationAutoScheduler';

```

#### `getVaccinationSuggestions(petId)`

```

```

## Troubleshooting

### Common Issues

#### 1. **No Vaccination Suggestions Generated**
- Check if pet has birth date and species set
- Verify vaccination services exist and are marked as `isVaccination: true`
- Ensure pet has existing vaccination records for booster calculations

#### 2. **Incorrect Due Dates**
- Verify pet birth date format in database
- Check timezone settings for date calculations
- Review vaccination series template configurations

#### 3. **Service Matching Failures**
- Ensure vaccination services have descriptive names
- Check service classification and vaccination flags
- Review service matching algorithm logic
